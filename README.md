# BusiGest

BusiGest é um Micro-SaaS em português que ajuda freelancers, pequenos comerciantes e prestadores de serviços a gerarem orçamentos e recibos profissionais em segundos pelo telemóvel ou computador.

O sistema deve ter as seguintes telas e funcionalidades:

1. Painel Principal (Dashboard): Um resumo visual com o total de dinheiro ganho no mês, quantidade de recibos gerados e um botão grande "Criar Novo Recibo/Orçamento".

2. Gerador Dinâmico: Um formulário onde o utilizador insere os dados do cliente, seleciona se é um "Orçamento" ou "Recibo", adiciona itens com nome, quantidade e preço (calculando o total automaticamente) e um botão para "Gerar PDF profissional".

3. Catálogo de Produtos/Serviços (Mini-Stock): Uma tela simples onde o utilizador pode deixar salvo o nome e o preço dos seus produtos ou serviços mais vendidos, para que ao criar o recibo ele possa apenas selecionar da lista em vez de digitar tudo novamente.

4. Histórico: Uma tabela que lista todos os recibos já gerados, com o status (Pago ou Pendente).

Design: Faça uma interface moderna, limpa, com cores profissionais (como azul escuro e branco), totalmente otimizada para telemóveis.
